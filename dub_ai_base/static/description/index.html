Key Features

Per-Company Configuration

Each company can have its own API keys and model preferences. Perfect for multi-company setups.

Dynamic Model List

Models are stored in database, not hardcoded. Sync available models directly from provider APIs.

Secure API Key Storage

API keys are stored securely in the database and managed through standard Odoo settings.

Easy Integration

Other modules can use this as a base to access AI capabilities without managing their own configuration.

Configuration

1. Go to Settings > AI Providers
2. Enter your API keys for each provider you want to use
3. Select the default model for each provider
4. Choose your default AI provider
5. Click "Sync Models" to fetch latest models from provider APIs
