The Model Context Protocol

USB-C for AI — now plugged into Odoo

MCP is an open standard developed by Anthropic that lets AI assistants talk to external tools and data through one uniform protocol. This module turns Odoo into an MCP server: AI agents can discover models, search, read, and — only when explicitly allowed — create, update or delete records.

Everything runs through OAuth 2.0 and respects the ORM's permissions. Nothing is exposed by default. You decide, per model, per field, per operation.

What's inside

Enterprise-grade features, by default

Native SSE transport

No bridge, no proxy, no polling. The server speaks MCP over Server-Sent Events directly.

OAuth2 authentication

Authorization Code + PKCE or Client Credentials. Dynamic Client Registration supported.

Deny by default

Install the module and nothing is exposed. Every user must be explicitly allowed.

Per-model CRUD rules

Granular flags for read, create, write and unlink — one rule per model.

PII masking

Flag sensitive fields as PII and let the server show d****e@domain.com instead of full values.

Field denylist & domains

Always hide fields like password, token, secret. Scope records with domains.

Whitelisted methods

AI clients cannot call arbitrary code — every callable is explicitly granted per model rule.

Rate limiting

Configurable sliding window per user/IP. Protect Odoo from runaway agents.

Full audit log

Every call recorded: user, IP, operation, model, status, request excerpt. With configurable retention.

How it works

From zero to AI-connected in four steps

1

Install the modules

Add dub_oauth2_provider and dub_mcp_server to your addons path, then install.

2

Create an OAuth2 client

Or let your AI assistant register itself via Dynamic Client Registration (RFC 7591).

3

Build your MCP configuration

Link it to a user or to the OAuth2 client. Add model rules. Mark PII fields. Configure the rate limit.

4

Connect your AI assistant

Point it at https://your-odoo.example.com/mcp/sse and grant consent. That's it.

Layered defence

Security at every level

Scoped to the user

Every MCP tool runs with the token owner's ORM context — record rules and Odoo ACLs still apply.

No secret leakage

Fields password, token, api_key, secret are always denied.

PII masking

Hide or partially obfuscate sensitive fields for specific AI agents.

Traceability

Full audit trail of every request, success or failure, with configurable retention.
