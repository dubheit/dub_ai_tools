What is MCP?

Model Context Protocol (MCP) is an open standard that allows AI assistants to securely access external data sources and tools. This module turns your Odoo instance into an MCP server, enabling AI tools to read, create, update, and delete records based on configurable permissions.

Key Features

Native SSE Transport
Direct connection from AI clients - no bridge or proxy required.

OAuth2 Device Flow
Secure authentication via browser. User approves access on first connection.

Granular Permissions
Control exactly which models and operations each AI client can access.

Audit Logging
Track all MCP operations with UI and configurable retention.

Rate Limiting
Built-in rate limiting to protect your Odoo instance.

Method Execution
Execute whitelisted methods on records with full control.

Quick Setup

1. Install dub_oauth2_provider module for authentication

2. Create an OAuth2 Client with Device Authorization grant type

3. Create an MCP Configuration linked to the OAuth2 client

4. Add Model Rules to define which models can be accessed

5. Configure your AI tool with SSE URL and client credentials

Client Configuration Example

Add this to your claude_desktop_config.json or equivalent: 

{
  "mcpServers": {
    "odoo": {
      "url": "https://your-odoo.com/mcp/sse",
      "transport": "sse",
      "headers": {
        "X-MCP-Client-Id": "your-client-id",
        "X-MCP-Client-Secret": "your-client-secret"
      }
    }
  }
}

On first connection, a browser window opens for OAuth2 authentication. After approval, the token is cached and reused automatically.

Endpoints

Endpoint Description
/mcp/sse MCP protocol endpoint (SSE transport)
/mcp/health Health check endpoint
/mcp/search_read REST API: Search and read records
/mcp/create, /write, /unlink REST API: CRUD operations
/mcp/methods REST API: List available methods for a model
/mcp/execute REST API: Execute whitelisted methods on records
